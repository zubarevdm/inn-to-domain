# Оценка качества

## Как собран набор

Набор из 35 организаций собран в два приёма.

Первая часть — компании, по которым ответ известен: крупный бизнес, средние
компании и вузы. Сюда специально отобраны трудные случаи: юрлицо не совпадает с
брендом (ООО «Интернет Решения» и ozon.ru), домен не выводится из названия
(ПАО «Ростелеком» и rt.ru), сайт закрыт от ботов, сертификат выпущен НУЦ
Минцифры.

Вторая часть — случайные организации из подсказок DaData по корням слов
(`eval/sample_companies.py`). Так в набор попали обычные ООО с типовыми
названиями и шесть ИП. У большинства из них сайта нет, и это важная половина
задачи: пайплайн должен молчать.

## Как ставились метки

Метка не может браться из ответа пайплайна, иначе это проверка себя на себе.
Порядок такой:

1. `eval/label_helper.py` собирает сырую выдачу по трём запросам без фильтров и
   проверяет, опубликован ли ИНН на сайтах-кандидатах.
2. Человек читает выдачу и назначает метку.
3. `eval/verify_labels.py` проверяет назначенную пару «ИНН, домен»: ищет ИНН и
   ОГРН на сайте.

В колонке `label_source` записано, на чём метка держится: `реквизиты` означает
найденный на сайте ИНН, `ручная проверка` — решение человека по выдаче.

Метка «сайта нет» (пустое поле) означает, что сайт не нашёлся при ручном
просмотре выдачи. Это не доказательство отсутствия сайта, и такие метки могут
быть слишком строгими.

## Что считается

- **точность (precision)**: доля верных среди выданных доменов. Главная метрика,
  потому что неверный домен в справочнике дороже пустого поля;
- **полнота (recall)**: доля найденных среди организаций, у которых сайт есть;
- **верных null**: как часто пайплайн правильно молчит;
- **ложных ответов**: выдал домен там, где сайта нет.

## Запуск

```bash
python eval/run_eval.py --modes search_only,verify,full
python eval/make_report.py
```

Результаты складываются в `eval/out/`, сводные таблицы — в `eval/out/tables.md`,
разбор — в [report.md](report.md).

## Оговорки

- Набор маленький, доверительные интервалы широкие. Для 35 наблюдений разница в
  два-три случая статистически незначима.
- Выборка смещена: крупные компании представлены сильнее, чем в ЕГРЮЛ.
- Прогон выполнялся через зарубежный VPN, часть российских сайтов при этом
  отвечает таймаутом. С российского адреса полнота будет выше.
